# HealthSense AI - Hospital NCD Screening Platform

## 🏥 Overview
HealthSense AI is a comprehensive Non-Communicable Disease (NCD) screening and referral platform.

## 🚀 Features
- AI Risk Assessment for Diabetes, Hypertension, CVD, Stroke, CKD
- Automated Referrals to specialists
- Multi-role Dashboard (Nurse, Specialist, Admin)
- Lab Test Management
- HealthHero Chatbot Assistant

## 📦 Installation
```bash
npm install
npm run dev
```

## 🎯 Roles
- **Nurse**: Patient registration, screening, archive
- **Specialists**: Referral review, lab ordering
- **Super Admin**: Analytics, user management
